## Post 1 (pakai 7 gambar)

gais, aku bikin aplikasi buat buka WhatsApp sama Telegram dalam satu jendela, namanya Twincxt 💬

gratis, ada buat Windows, macOS, sama Linux. nggak perlu bolak-balik tab browser lagi, tinggal Ctrl+Tab

ceritanya di thread 🧵👇

## Post 2: fitur

yang bikin aku betah pake sendiri:

• sidebar dibagi dua, WhatsApp di atas, Telegram di bawah, jumlah chat belum dibaca kelihatan
• blur chat, nama, foto profil, sama media. arahin kursor buat baca. aman dipake di tempat rame
• video call tetap di jendela utama, pindah ke jendela terpisah cuma kalo kamu mau
• notifikasi bisa banner, kedip di taskbar, atau dua-duanya
• login kesimpen, buka lagi nggak perlu scan ulang

## Post 3: ringan

ukurannya kecil karena nggak bawa browser sendiri. Twincxt pake mesin browser bawaan tiap OS: WebView2 di Windows, WebKit di macOS, WebKitGTK di Linux

tampilannya juga ngikutin OS-nya, gaya Windows 11, macOS, sama GNOME. update berikutnya masuk sendiri dari dalam aplikasi

## Post 4: asal-usul

Twincxt nggak muncul dari nol ya. aku kembangin dari whatsapp-web.view bikinan Adytm404, aplikasi WhatsApp Web ringan buat Windows. kredit penuh buat yang bikin 🙏

dari situ aku kembangin: tambah Telegram, sidebar dua bagian, blur chat, updater, terus bikin versi macOS sama Linux

## Post 5: link

mau coba? download di github.com/rashiiddsr/twincxt (bagian Releases, pilih sesuai OS)

catatan: ini bukan aplikasi resmi WhatsApp, Meta, atau Telegram ya. di Linux, panggilan suara/video tergantung distro. nemu bug atau mau request fitur, komen aja di sini 🙌
